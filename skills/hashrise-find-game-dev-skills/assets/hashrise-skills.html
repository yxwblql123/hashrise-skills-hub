把你的开发流程也做成 Skill 导航

本站不是静态页面。它是一套 技能索引 + 可视化导航 + 目录 JSON + 完整性校验 的完整骨架： 目录条目带 commit 与内容 sha256，构建时校验，构建脚本生成自包含单文件页面， 还能打包成可导入的技能包。

  • 策展可重跑 —— scripts/curate.py 从本地克隆的候选仓库生成目录
  • 哈希防篡改 —— 每条记录锁定文件 sha256 与来源 commit
  • 离线可用 —— 构建产物是单文件 HTML，断网也能翻
  • 可导成技能 —— 一键打包 ZIP，导入任意支持 SKILL.md 的客户端
