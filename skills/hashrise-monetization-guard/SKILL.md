# 变现系统设计与 P2W 红线守卫

放置类游戏的变现最容易滑向 pay-to-win。本技能给出 Hashrise 的三条变现支柱、硬红线与可执行的审查方法。

## 三条变现支柱

| 类型 | 形式 | 玩家获得 | 设计意图 |
|------|------|---------|---------|
| 激励视频 Rewarded Video | 看广告 | 限时加速 / 离线翻倍 | 无门槛、高频率、低侵入 |
| 去广告订阅 Remove-Ads | 订阅 / 买断 | 去广告 + 永久离线增益 | 核心付费点 |
| 软内购 Soft IAP | 算力包 | 一次性货币/算力注入 | 可选，时间可肝回 |

## 三条硬红线

### 红线 1 · 付费只加速，绝不锁内容

- 免费玩家 **0 付费可以通关 MVP 全部内容**。
- 不出售**独占内容**：独占矿机、独占币种、独占关卡、独占剧情。
- 所有内购内容都能用游戏内货币在**合理时间**内肝出来。
  - "合理"的判定：软内购档位表里写明「≈ N 分钟肝度」，且 N 不得小到让肝变成负担。

### 红线 2 · 不提升数值上限，只压缩时间

广告与内购只能让玩家**更快到达**某个状态，不能让玩家到达**别的状态**。

| 允许 | 禁止 |
|------|------|
| 限时产出 ×2 | 永久产出 +500% |
| 离线时长上限 +4h | 离线收益倍率无限 |
| 一次性注入货币 | 出售带特殊词缀的独占矿机 |
| 去广告 | 付费解锁必要功能 |

### 红线 3 · 变现不靠打断

- 激励视频是**玩家主动触发**的，不能自动弹。
- 有**疲劳护栏**：广告有日上限。
- 留存钩子必须是**玩法本身**（离线收益 + 叙事），不是广告弹窗。
- 指标红线：广告观看率 < 30%，或 7 日留存因广告下滑 → **降频**。

## 疲劳护栏的具体设计

Hashrise 的护栏配置（可直接参照的粒度）：

| 类型 | 上限 |
|------|------|
| 加速类广告（×2 持续 4h） | 每日 5 次 |
| 离线翻倍 | 独立，不占 5 次额度 |
| 秒修（过热重损/断电恢复） | 独立，冷却 30 分钟 |

**为什么是 5 而不是 10**：加速倍率是 ×2 而不是 ×10。倍率越高，免费玩家的体感被拉开得越狠，"没法玩"的临界点越近。倍率与次数是一对旋钮，要一起调。

## 软内购定价：写清肝度

每个档位都必须标注"等价游戏内货币"与"≈ 多少分钟肝度"：

| 档位 | 定价 | 内容 | 等价进度 |
|------|------|------|----------|
| 新手包 | $0.99 | 1000 货币 + 1 台中阶矿机 | ≈ 8 分钟肝度 |
| 标准包 | $4.99 | 8000 货币 | ≈ 1 小时肝度 |
| 矿主包 | $9.99 | 20000 货币 + 冷却加速 | ≈ 3 小时肝度 |

写"≈ 8 分钟肝度"而不是只写"1000 货币"，是为了让评审能直接判断"这是否已经构成 pay-to-win"。

**档位设计原则**：
- 最低档要足够便宜，让犹豫的人也能接受（冲动消费）。
- 最高档的**性价比不应明显优于**低档叠加太多，否则中间档失去意义。
- 不做"限时礼包"制造焦虑。

## 订阅档位

去广告订阅是**纯增益非必需**：免费玩家靠肝可以达到同等进度，只是慢。

```
周订阅 ¥6 / 月订阅 ¥18 / 永久买断 ¥68
```

订阅附带的永久增益（离线效率 +25%、离线时长上限 +4h）仍受**系统绝对硬上限**约束（24h）。任何增益都不能突破硬上限——否则买了订阅的离线收益会指数级领先，间接构成 P2W。

## 审查清单

设计或评审一个变现方案时，逐条核对：

- [ ] 免费玩家 0 付费可以完成全部 MVP 内容
- [ ] 没有独占内容出售（矿机 / 币种 / 关卡 / 剧情 / 皮肤）
- [ ] 每个内购档位都标注了"≈ N 分钟肝度"
- [ ] 每个内购档位都能在合理时间内用游戏内货币肝出
- [ ] 所有付费效果都是**时间压缩**，不是数值上限提升
- [ ] 付费效果不突破系统硬上限（如离线时长上限）
- [ ] 广告全部为玩家主动触发，无自动弹出
- [ ] 每类广告都有明确频次上限与独立冷却
- [ ] 广告观看率与 7 日留存有监控指标与降频触发条件
- [ ] 去广告订阅的收益在**免费玩家可达范围内**
- [ ] 留存钩子来自玩法（离线收益 / 叙事），不来自广告打断
- [ ] 地区定价与年龄分级合规已确认（涉及题材需标注"虚构"）

## 违规信号速查

出现以下任何一条，直接打回：

- 出售"永久解锁产出倍率"且该倍率无法通过游戏内货币达到
- 出售独占矿机或独占币种
- 内购档位标注的肝度 < 3 分钟（实质是强制付费）
- 广告自动弹出或强制插屏
- 付费解锁功能而非加速功能
- 订阅加成突破系统硬上限
- 靠"限时礼包"制造焦虑作为主要收入来源
